
# PHP Authentication System

A beginner-friendly PHP authentication project featuring a clean interface inspired by Valorant.

## Overview

This project was developed to practice PHP fundamentals, form handling, input validation, and session management.

It includes login, registration, password recovery, a user dashboard, and a profile page.

## Features

- Login page with credential validation
- Registration form with input validation
- Email and password validation
- Forgot password interface
- Session-based access protection
- User dashboard
- Profile page
- Logout functionality

## Technologies Used

- HTML5
- CSS3
- PHP
- XAMPP

## Installation

1. Install XAMPP.
2. Start Apache from the XAMPP Control Panel.
3. Copy the project folder into:

   `C:\xampp\htdocs\`

4. Open your browser.
5. Visit:

   `http://localhost/TP_Exercices/SignIN.php`

## Current Limitations

- Login currently uses hardcoded demonstration credentials.
- Registration validates input but does not save users to a database.
- Password recovery is a demonstration interface only.
- Remember Me functionality is not implemented.
- MySQL integration is not implemented yet.
